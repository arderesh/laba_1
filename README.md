# toolkit

Калькулятор арифметических выражений и конвертер величин (длина, масса, температура)

## Установка

```bash
pip install -e ".[dev]"
```

# Команды

## 1) Вычисление выражения
`python -m toolkit calc "(выражение)"`
### Пример:
`python -m toolkit calc "2+3*4"`

Результат: `14`

## 2) Конвертация
`python -m toolkit convert [value] --from [unit] --to [unit]`
### Пример:
`python -m toolkit convert 1000 --from mm --to m`

Результат: `1`

## 3) Справка
`python -m toolkit --help`

## 4) Коды возврата: 
`0` - команда выполнена успешно, `2` - пользовательская
ошибка.

# Калькулятор

В выражении - целые и вещественные числа, нет зависимости от пробелов между символами.
Поддерживаются унарные `+` и `-` перед числом: `-2`, `+5`.
Знак считается унарным, если слева от него нет числа или стоит оператор.

### Последовательность выполнения:

`tokenize` (разделение на токены) -> `validate` (проверка корректности выражения и чисел) -> `to_npr` (конвертер в обратную польскую запись) -> `eval_npr` (выччисление результата по обратной польской записи).

### Пример разбора:
`-2*-3`: токены `UMINUS 2 MUL UMINUS 3` —
1) оба минуса унарные (первый в начале выражения, второй после `*`);

2) обратная польская запись `2 UMINUS 3 UMINUS MUL` (она реализована по следующему правилу: число - добавляется в результирующий список,
а знаки, помещаются в стек, если ранг знака выше, чем ранг последнего добавленного в стек знака. Если это нарушается,
из стека переносятся предыдущие знаки в результирующий список (начиная с вершины стека и до 0-го индекса));

3) алгоритм вычисления: когда в стеке подряд идут два числа, а после них - знак, вычисляется значение этого выражения, 
таким образом выполняется программа до момента, пока не останется последнее число (кроме него не должно быть ничего больше), 
которое и будет являться результатом; 

4) в стеке унарные минусы загоняются в числа,
после которых они стоят: `2 -> -2`, `3 -> -3`,
`-2*-3=6`.

# Конвертер

Для вычисления длины сначала все переводится в метры, а потом в соответствующую величину, температура - в градусы Целсия, масса - в граммы.

Поддержка следующих величин:
    Длина: мм, см, дм, м, км
    Масса: мг, г, кг
    Температура: Цельсии, Кельвины, Фаренгейты

### Добавление новой единицы: 
Добавлена единица дециметр(дм).

# Ошибки

Все виды ошибок хранятся в файле `errors.py`.

`EmptyExpressionError` (пустое выражение), `InvalidTokenError` (`2+a`, `2..3` - неизвестный символ),
`InvalidExpressionError` (`2*/3`, `2+` - неверное выражение), `DivisionByZeroError` (`1/0` - деление на ноль),
`UnknownUnitError` - неизвестная величина (по типу byte, lightyear и прочее), `IncompatibleUnitsError` (`kg → m`; тест -
в `tests/test_converter.py` - перевод величин из разных групп), `BelowAbsoluteZeroError` - температура ниже абсолютного нуля,
`InvalidValueError` - неверное значение.

# Округление через Decimal

Политика округления: сложение, вычитание и умножение выполняются в стандартной 
десятичной арифметике `decimal.Decimal`; деление - с точностью до 28 знач цифр,
округление - стандартное Python округление;
результат возвращается как `float`, а целые числа представляются без плавающей точки.
